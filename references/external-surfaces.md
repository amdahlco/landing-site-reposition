# External surfaces

Surfaces outside the repo drift silently: no CI sees them, and buyers often
meet them before the site. Once a pivot is merged and settled, propose
matching copy for each one.

## The surfaces

Take an inventory first, then draft. Common ones:

| Surface | Budget |
| --- | --- |
| LinkedIn company tagline | About 120 characters before it truncates |
| LinkedIn about section | The first two lines show before "see more" |
| Team email signature | One line under the logo, about 45 characters |
| GitHub org description | One line |
| X or Bluesky bio | 160 characters |
| Event blurbs, podcast one-liners | Whatever the host gives |

State the character count beside every proposal.

## Rules

- **Company surfaces only.** Never draft a person's own headline or bio,
  founders included. Copy handed to a person reads as the company scripting
  its people. If someone wants matching copy for their profile, that is
  their request to make.
- **Everything derives from the kernel pair.** Never a third phrasing of
  what the company is. Surfaces read together (the LinkedIn page and the
  GitHub org in one search) must not run the same headline template twice.
- **Proposals only.** These ship by a person pasting them. Give one
  ready-to-paste block per surface, one recommendation with the reason,
  alternates below.
- **A signature row under the logo takes the brand line**, not the outcome
  line: the outcome line is second person and reads as a pitch under
  someone's phone number.
- **Test unsettled words here first.** External surfaces are the cheap trial
  before a word earns homepage space.

## A locked format can pin a retired line

If the team uses a fixed signature format, the positioning row can carry a
line the site retired months ago, and no grep finds it, because it lives in
each person's mail settings. Every pivot ends by re-reading that row against
the new kernel. A mismatch is NAMED to the format's owner, never re-typed
quietly.

## Telling the team

Ask before sending anything. When you do tell them:

- Send a link to one page that always shows the current block, not the
  block itself. Some mail tools strip images from pasted HTML, and a new
  link per pivot leaves old ones going stale in inboxes.
- A week later, search for the retired line in recent mail and name who has
  not switched. That is the only check that proves the surface is current.
